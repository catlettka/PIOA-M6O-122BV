# Описание структуры проекта

## Типы баз данных

### In-memory Database
База данных хранит все таблицы в оперативной памяти.
- высокая скорость работы
- данные существуют только во время выполнения программы
- после завершения работы все данные удаляются

### JSON File Database
Каждая таблица сохраняется в отдельный JSON-файл в каталоге `data_json`
- автоматическое сохранение данных
- сохранение структуры таблицы и записей
- данные доступны после повторного запуска программы

### CSV File Database
Каждая таблица сохраняется в отдельный CSV-файл в каталоге `data_csv`
- простое текстовое представление данных
- сохранение схемы таблицы в первой строке файла
- данные доступны после повторного запуска программы

## Структура проекта

- `src/db/backend/memory.py` — логика базы данных в оперативной памяти
- `src/db/backend/errors.py` — обработка всех исключений
- `src/db/backend/file_json.py` — файловая реализация базы данных с хранением таблиц в формате JSON
- `src/db/backend/file_csv.py` — файловая реализация базы данных с хранением таблиц в формате CSV
- `src/db/tui.py` — консольный интерфейс пользователя
- `src/db/main.py` — точка входа
- `tests/` — модульные тесты проекта

## Основные возможности

### Работа с таблицами
- создание таблиц
- выбор активной таблицы
- переключение между таблицами
- просмотр списка таблиц

### CRUD операции
- добавление записей
- просмотр записей
- обновление записей
- удаление записей

### Дополнительно
- сортировка по полю (по возрастанию / убыванию)
- фильтрация данных
- сохранение данных в файлы

## Обработка ошибок

Реализованы пользовательские исключения:
- TableNotCreatedError — таблица не создана
- TableAlreadyExistsError — таблица уже существует
- EmptyTableError — таблица пуста
- EmptyFieldError — пустое поле
- InvalidFieldError — неверное имя поля
- InvalidTypeError — неверный тип данных
- ValidationError — ошибка валидации
- InvalidSchemaError — некорректная схема таблицы
- RecordNotFoundError — запись не найдена
- FileStorageError — ошибка работы с файловым хранилищем
- InvalidStorageDataError — повреждённые или некорректные данные в файле

## Запуск теста:
